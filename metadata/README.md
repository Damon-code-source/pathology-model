# Metadata

- `tcga_lihc_slide_ids.csv`: 361 public TCGA-LIHC diagnostic slide IDs evaluated by both binary classifiers. `case_id` is derived from the first three TCGA barcode fields.
- `training_manifest_template.csv`: schema only. It does not contain study participants or raw data.

The TCGA manifest is an identifier list, not a redistribution of images or protected clinical data.
